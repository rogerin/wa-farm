04 / INTEGRAÇÃO COM SISTEMAS DE MENSAGERIA KEYCORE • PARETO DE PAREAMENTO
04

Como Conectar o Emulador ao seu Sistema de Mensageria

Depois de fazer login com o número novo no WhatsApp do emulador, abra Mais opções (⋮) > Aparelhos conectados > Conectar um aparelho e escolha um dos 3 métodos abaixo:

Mais Rápido • Zero Uso de Câmera

Pareamento via Código de 8 Dígitos no ADB

1. Na tela de câmera do WhatsApp no emulador, toque em "Conectar com número de telefone" na parte inferior.
2. Gere o código de 8 caracteres no seu sistema de mensageria (Evolution API, WAHA, Baileys, Z-API).
3. Rode o comando ao lado para o script digitar o código instantaneamente no emulador.

# Envia o código de 8 dígitos direto para a Conta #1 (wa_01): $ ./wa-farm.sh pair 1 ABCD1234 [wa-farm] Digitando código 'ABCD1234' em wa_01 (emulator-5554)... [OK] Código enviado para a tela do WhatsApp!
Câmera Virtual 3D Nativa

Injeção Direta do PNG do QR Code (virtualscene)

1. Salve um print apenas do QR Code exibido pelo seu sistema de mensageria (qrcode.png).
2. Execute o comando ao lado: ele grava a imagem no arquivo Toren1BD.posters da parede e mesa virtual do emulador.
3. Segure Option/Alt + teclas W/A/S/D ou mouse na câmera do emulador para enquadrar.

# Injeta a imagem PNG do QR Code na câmera traseira de wa_01: $ ./wa-farm.sh qr 1 ~/Desktop/qrcode.png [OK] QR Code injetado na câmera virtual de wa_01!
Passthrough de Vídeo

Leitura via Webcam do Host ou OBS Virtual Camera

Caso prefira apontar um QR Code de outra tela para a webcam do seu Mac/Linux ou transmitir uma janela via OBS Virtual Camera, basta iniciar a instância com a flag --webcam.

# Inicia o emulador wa_01 conectando a câmera traseira à webcam0: $ ./wa-farm.sh start 1 --webcam
05 / REFERÊNCIA COMPLETA DA CLI (WA-FARM.SH) KEYCORE • MANUAL DE OPERAÇÃO
05

Catálogo de Comandos Executáveis

Todos os comandos podem ser executados diretamente com ./wa-farm.sh, via atalho global wa-farm ou via npm run wa.

Comando Oficial Função Operacional Ação
./wa-farm.sh bootstrap 1 Tudo em 1: Instala SDK/APK (se faltar), cria wa_01, inicia o emulador, aplica debloat e abre o WhatsApp.
./wa-farm.sh setup Instala o Android Emulator, a imagem AOSP pura (android-31) e baixa o WhatsApp.apk oficial da Meta.
./wa-farm.sh create all Cria os 7 celulares virtuais (wa_01 a wa_07) com config.ini otimizado (896 MB RAM, 360x640).
./wa-farm.sh start 1 Inicia o emulador da Conta #1 (emulator-5554) com janela gráfica compacta.
./wa-farm.sh start all --headless Inicia todas as 7 contas simultaneamente em segundo plano sem janela (-no-window -gpu off).
./wa-farm.sh install-wa 1 Aplica debloat no Android via ADB, instala o WhatsApp.apk, libera permissões e abre o app.
./wa-farm.sh qr 1 ./qrcode.png Injeta a imagem PNG do QR Code na cena virtual da câmera traseira do emulador.
./wa-farm.sh pair 1 ABCD1234 Digita o código de pareamento de 8 dígitos diretamente no WhatsApp via ADB.
./wa-farm.sh status Exibe tabela com as 7 contas, porta ADB, status e consumo real de RAM em MB.
./wa-farm.sh stop all Desliga graciosamente todos os emuladores em execução, liberando 100% da RAM.
./wa-farm.sh heartbeat Liga cada conta em modo headless por 60 s (1 por vez) para renovar a sessão Multi-Device de 14 dias.

Protocolo de Blindagem para Números Novos

Chips recém-ativados possuem score de confiança inicial sensível nos sistemas da Meta. Siga os 3 pilares abaixo ao operar suas 7 contas:

Isolamento de Hardware

1 Conta = 1 AVD Exclusivo

Nunca faça login de vários números novos limpando os dados do mesmo emulador. O wa-farm cria wa_01 a wa_07 com partições userdata-qemu.img e Device IDs totalmente independentes.

Atenção • Warm-up

Janela de Estabilização (15–30 min)

Após validar o SMS/Ligação do número novo no emulador, configure nome e foto de perfil, troque 2 ou 3 mensagens manuais e aguarde 15 a 30 minutos antes de escanear o QR Code da API de mensageria.

Automação Semanal

Heartbeat Programado no Cron

Agende ./wa-farm.sh heartbeat uma vez por semana no crontab. Cada celular virtual sincronizará com a Meta por 60 segundos em background sem consumir RAM no dia a dia.
